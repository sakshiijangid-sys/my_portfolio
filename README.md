Focuses on aesthetic, utilizing clean grids, subtle noise textures, and smooth animations to create a premium digital experience.

🛠️ Core Languages & Frameworks

TypeScript: 🛡️ Used throughout the project to ensure type safety, better developer experience, and fewer runtime errors.
React.js: ⚛️ The foundation of the UI, enabling a modular, component-based architecture for maintainability.
Node.js & Express.js: 🟢 Powers the backend strategy for handling data and API integrations (ready for full-stack expansion).
MongoDB: 🍃 The preferred NoSQL database for managing project data and user information flexibly.
Tailwind CSS: 🎨 Utilized for rapid, utility-first styling, ensuring a consistent and modern design system across the app.
GSAP (GreenSock): 🎬 Driving the professional-grade motion design, including scroll-triggered reveals and hero animations.

✨ Key Features

🎓 Academic Timeline: A detailed section showcasing educational milestones from schooling to B.Tech, highlighting academic excellence.
📂 Multi-Stage Project Gallery: Separate showcases for Published Work (live links) and In-Development projects (interactive modals).
🔍 Skill Matrix: A comprehensive breakdown of both Technical Skills (like React, Next.js) and Soft Skills (like Creativity, Adaptability).
📬 Integrated Contact Hub: A sleek footer providing direct paths to professional communication via Email and LinkedIn.
🖱️ Custom Interaction: Includes smooth "Back to Top" scrolling, hover-state feedback, and scroll progress tracking.
